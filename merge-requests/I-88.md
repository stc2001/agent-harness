## 变更摘要

按用户要求补充本地 pre-push 护栏，.githooks 不入库：

- 本地创建 .githooks/pre-push（executable）+ git config core.hooksPath .githooks；
- .gitignore 新增 .githooks/（本 MR 唯一 tracked 变更）；
- hook 规则：
  - localhost / 127.0.0.1 / ::1 / file:// / 本地路径 -> 放行（私有 soft-serve 正常推送）；
  - 其他远端：只允许 root（无父）快照提交；历史提交一律拒绝并打印快照命令；
  - 快照树含 sessions/、.soft-serve/、.venv/、.scratch/、diary/、node_modules/、
    docs/harness_doc/deepseek_keys_for_test 时拒绝；
  - ALLOW_PUBLIC_PUSH=1 可紧急放行（带 warning）。
- 说明：hook 不能缩小 push；它只拒绝危险推送，latest-only 仍靠 commit-tree 快照。

## 影响面

- tracked 文件仅 .gitignore；.githooks 本地文件被忽略。
- 不影响本地 soft-serve 推送（已实测本分支 push 正常）。
